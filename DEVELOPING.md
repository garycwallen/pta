# DEVELOPING

## Getting Started
1. `npm install` in the root directory
1. `cd lres-pta-rsvp-api` to change into the API directory
1. `npm install` to install the API dependencies
1. `cd ../` to change back to root directory
1. `npm run dev` to run Web and API server

## Instructions
For Event Day:
Just run the import script with your updated Excel file:
bashnode importToSupabase.js YourEventFile.xlsx
